# Add Art Design Studio — Web Design Case Study

Case study in English for the Guestcentric application, covering brand strategy, UX/UI design, HTML/CSS/JavaScript development and AI-assisted workflows.

## Publish the site

1. In this repository, select **Add file → Upload files** and upload the prepared `index.html` (with its images embedded).
2. Commit to the `main` branch.
3. Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
4. Verify the published page at https://aryaednyr.github.io/addart-case-study/.

The HTML is self-contained: no separate image files are needed.
